## Notes

Distinction worth keeping: skill-deploy's `--project` flag links repo
skills into a project's `.claude/skills/` — per this rule that flag is
not the tool for the promotion end state (it creates exactly the
project→library pointer the user forbids). If the user later wants the
flag removed or doc-fixed in skill-deploy, that edit needs explicit
global-targeting authorization (skill-forge R1).
