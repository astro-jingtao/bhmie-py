claim: >
  To build a Python Fortran extension with f2py + meson-python on Windows
  using conda-forge flang, install flang AND the separate flang-rt_win-64
  runtime package, wrap the whole build in a .bat script that activates
  vcvarsall x64 + the conda env and exports AR/RANLIB=llvm-*, the flang
  resource-dir on LIB, and FFLAGS=-static-libflangrt, and declare the f2py
  custom_target in the ROOT meson.build with every implementation-bearing
  Fortran source also listed as an extension_module source.
