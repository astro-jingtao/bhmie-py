## Notes

The near-miss is the valuable part: an untested `'flang'` guard compiles
fine on Linux (gfortran skips the branch either way) and only breaks the
Windows flang build — the exact environment that needed the flag. Always
confirm the id from `meson-info/intro-compilers.json` of a real build
before writing a `get_id()` comparison.
