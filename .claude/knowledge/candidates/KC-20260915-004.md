## Notes

General shape of the trap: string-concatenating an operator-bearing
prefix with ternary branches is only safe when EVERY branch starts
with a valid operator for that prefix. The masking effect (one branch
accidentally valid) is what makes it survive review — a static test
on the workflow file is the cheap countermeasure.
